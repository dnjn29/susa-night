# 수산 궁의 밤

성경 에스더서 10장을 10막으로 옮긴, 선택으로 진행되는 궁중 드라마 게임입니다.
초등 고학년(12살쯤)이 혼자 읽고 할 수 있는 말로 쓰였고, 모르는 낱말과 규칙은 전부 게임 안에서 알려 줍니다.

플레이어는 페르시아에 사는 유대인 소녀입니다. 이름이 두 개입니다. 집에서는 하닷사, 밖에서는 에스더.
10개의 막을 지나는 동안 왕비가 되고, 자기 민족 전부가 죽게 될 위기를 만납니다.

**[▶ 바로 해보기](#)** &nbsp;·&nbsp; 브라우저만 있으면 됩니다. 설치도 서버도 필요 없습니다.

## 어떤 게임인가

장면마다 선택지가 2~3개 나오고, 고르면 이야기가 이어지면서 숫자 네 개가 오르내립니다.
되돌릴 수는 없습니다. 10막까지 가면 결말이 나옵니다.

핵심은 **장면이 두 종류라는 것**입니다.

### 빨간 표시가 있는 장면 — 성경에 분명히 적혀 있는 자리

> 📖 **이 장면은 성경에 분명히 적혀 있다.** 성경과 다르게 고르면 이야기가 여기서 끝난다.

고르기 **전에** 이 표시가 뜹니다. 여섯 군데 있습니다.

| 막 | 장면 | 무엇을 고르나 |
|---|---|---|
| 2막 | 헤개의 뜰 | 왕에게 갈 때 무엇을 가져갈까 |
| 2막 | 왕을 죽이려는 계획 | 누구 이름으로 알릴까 *(여기만 6막에서 끝납니다)* |
| 4막 | 혹시 이때를 위해서가 아닐까 | 갈까 말까 |
| 5막 | 금 지팡이 | 지금 말할까 미룰까 |
| 8막 | 되돌릴 수 없는 종이 | 두 번째 편지를 어떻게 쓸까 |
| 9막 | 부림절 | 명절을 무슨 날로 정할까 |

### 표시가 없는 장면 — 성경에 적혀 있지 않은 자리

무엇을 골라도 괜찮습니다. 대신 여기서 쌓은 숫자가 4막과 5막을 넘을 힘이 됩니다.
1막 전부, 2막의 1년과 왕 앞에 선 밤, 3막 하만과의 대면, 6막 그 밤, 7막 어떤 말로 말할까가 여기 듭니다.

7막을 자유 장면으로 둔 이유가 있습니다. 세 가지 말투가 전부 에스더가 실제로 한 말 안에 들어 있어서,
순서만 다를 뿐 틀렸다고 할 수 없기 때문입니다.

## 숫자 네 개

| 숫자 | 하는 일 |
|---|---|
| **왕의 마음** | 5막에서 왕 앞 안뜰에 들어갈 때 필요합니다 |
| **궁궐 사람들** | 중요한 순간에 왕의 마음 대신 받쳐 줍니다 |
| **용기** | 4막에서 모자라면 "가겠다"는 말이 잠깁니다 |
| **하만의 의심** | 이것만은 낮을수록 좋습니다 |

꼭 넘어야 하는 시험이 두 번 있습니다.

- **4막** — 목숨을 걸겠다고 말하려면 용기 5 **또는** 궁궐 사람들 7
- **5막** — 안뜰에 들어가려면 왕의 마음 4 **또는** 궁궐 사람들 6

둘 다 조건이 두 가지입니다. 왕의 마음을 못 얻었어도 궁궐 사람들을 모아 뒀으면 통과합니다.

**하만의 의심**은 두 군데서 실제로 발목을 잡습니다.
4 이상이면 5막 시험이 어려워지고(왕의 마음 6 또는 궁궐 사람들 8), 6 이상이면 7막에서 하만이 먼저
왕에게 험담을 해서 왕의 마음이 1 깎입니다.

## 결말 열한 개

**회색 도장** — 성경과 다르게 골라서 도중에 끝난 결말. 여덟 개입니다.

| 끝나는 곳 | 결말 |
|---|---|
| 2막 | 다시 부름받지 못하다 |
| 4막 | 입을 다문 왕비 |
| 5막 | 내밀어지지 않은 금 지팡이 |
| 5막 | 하룻밤을 내준 왕비 |
| 6막 | 빈 문지방 |
| 8막 | 너무 상냥한 편지 |
| 8막 | 먼저 쳐도 된다는 편지 |
| 9막 | 숫자만 남은 명절 |

이 결말에는 「이야기는 여기서 끝났습니다」가 뜨고, 성경에서는 어떻게 되는지 알려 준 다음
**갈라진 막으로 돌아가는 버튼**을 줍니다. 그 막의 숫자까지 그대로 복원됩니다.

**금색 도장** — 성경대로 끝까지 간 결말. 쌓아 둔 숫자로 셋이 갈립니다.

- **부림의 빛** — 궁궐 사람들 10 이상 + 용기 10 이상
- **하닷사라는 이름** — 용기 10 이상

## 성경을 같이 펴 놓고 해도 좋습니다

- 장면마다 아래에 📖 표시로 몇 장 몇 절인지 적혀 있습니다
- 고른 **다음에** 성경에서는 어떻게 했는지 알려 줍니다. 같은 걸 골랐으면 그렇다고 말해 줍니다
- 막이 끝날 때 그 장에서 꼭 볼 절을 몇 개 집어 줍니다
- 「진짜 성경 이야기」를 누르면 어디까지가 성경이고 어디부터가 지어낸 것인지 막마다 알려 줍니다
- 어려운 낱말은 밑줄을 누르면 뜻과 그 말이 나오는 구절이 같이 나옵니다

성경 인용은 **개역개정**을 따랐습니다. 저작권이 있는 번역이라 본문을 길게 옮기지 않고,
구절 번호와 요약을 주는 방식으로 썼습니다. 직접 인용한 것은 에스더 4장 14절과 16절 두 군데뿐이고
출처를 밝혀 두었습니다.

## 일부러 선택지를 두지 않은 자리

9막에서 에스더가 수산에 하루를 더 달라고 청하는 대목(에 9:13)에는 고를 것을 두지 않았습니다.

규칙대로라면 거기도 성경대로 골라야 하는 자리입니다. 그런데 그러면 아이가
"300명을 더 죽이게 해 주세요"를 눌러야 이기는 게임이 됩니다. 성경은 에스더가 그렇게 청했다고
적기만 하고 **왜 그랬는지는 적지 않습니다.** 어른들도 읽기 어려워하는 자리라 정답으로 세우기가
어려웠습니다. 그래서 거기는 성경이 적은 대로만 지나가고, 게임 안에서도 그 이유를 그대로 밝힙니다.

## 파일 구성

```
susa-night.html        게임 원본. 이것 하나만 고치면 됩니다.
index.html             GitHub Pages 용. susa-night.html 에서 자동 생성됩니다. 직접 고치지 마세요.
tools/build-pages.mjs  index.html 을 만드는 스크립트
```

`susa-night.html` 은 Claude 아티팩트용 형식이라 `<!doctype>`, `<html>`, `<head>`, `<body>` 가 없습니다.
아티팩트 플랫폼이 게시할 때 그 껍데기를 자동으로 씌워 주기 때문입니다.
GitHub Pages 는 파일을 그대로 내보내므로 껍데기가 없으면 quirks 모드로 렌더링됩니다.
그래서 빌드 스크립트가 같은 껍데기를 씌운 `index.html` 을 따로 만듭니다.

## 고치는 법

`susa-night.html` 을 고친 다음, Node 가 있으면:

```bash
node tools/build-pages.mjs
```

그리고 두 파일을 함께 커밋하면 됩니다.

게임 내용은 전부 그 파일 하나의 `SCENES` 와 `ENDINGS` 안에 들어 있습니다.
장면 하나는 이렇게 생겼습니다.

```js
'a5-2':{act:5, title:'금 지팡이', must:true,   // must:true 면 빨간 표시가 붙는 자리
  t:[ /* 본문 문단, 대사, 성경 참조 */ ],
  c:[
    {tag:'잔치에 부른다', x:'...', e:{mang:1, ui:-1}, canon:true,   // canon:true 가 성경대로
     b:'성경에서는 ...', bref:'에 5:4', to:'a5-3'},
    {tag:'지금 고발한다', x:'...', e:{dam:2, ui:3}, to:'E.night'}   // 성경과 다르면 조기 엔딩으로
  ]}
```

외부 라이브러리는 쓰지 않습니다. 불러오는 것은 Google Fonts 뿐입니다.
진행 상황은 브라우저의 localStorage 에만 저장되고 아무 데도 보내지 않습니다.
